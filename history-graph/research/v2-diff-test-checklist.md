# V2 作成チェックリスト（diff 実測用・最小手順）

目的：Model Properties Diff の「変更が立つ diff」を実測するため、既存モデルに最小の変更を加えた V2 を1回だけ登録する。
所要時間の目安：10〜15分（Revit 操作 5分＋アップロードと処理待ち）。

## 対象ファイル
- `Snowdon Towers Sample Structural.rvt`（V1、33.8MB、SHA-256: 12f45d230056fb7f5af159887f8f82f2695aaf63f9a2f567a56869b249c38942）
- ローカル保存先：~/workspace/forma-hands-on/test-models/
- ダウンロードリンク（2026-11-19 01:13 JST まで有効）：https://muse.ai/files/1421767251020506/1692299512533356/hzhq6t7p0t7pa44g202sojtl/Snowdon_Towers_Sample_Structural.rvt

## 手順

### 1. ファイルを開く
- ダウンロードした .rvt を Revit で開く（バージョンは手元のもので可）。
- ファイル名は変えない（バージョン登録時に同じアイテムとして上げるため）。

### 2. 変更を4つだけ加える（diff の型を一通りカバーする最小セット）
どれも「元に戻せる・モデルを壊さない」場所で。やった要素の **要素ID**（管理タブ → 選択した要素のID）か、要素名をメモする。

| # | 操作 | 内容 | diff で期待される結果 |
|---|------|------|----------------------|
| 1 | 追加 | 既存の要素を1つコピーして少しずらして置く（例：基礎・柱・梁のどれか1つ） | 追加 1 |
| 2 | 削除 | 要素を1つ削除する（全体に影響しない端の要素） | 削除 1 |
| 3 | 移動 | 要素を1つ、500mm 程度移動する（形は変えない） | 変更 1（移動 / Transform） |
| 4 | プロパティ変更 | 要素を1つ選び、テキスト系パラメータ（例：「コメント」欄）に `diff-test` と入れる | 変更 1（プロパティのみ） |

メモの例：「追加＝1階の柱をコピー、ID 123456／削除＝…」のように4行で十分。

### 3. 保存
- そのまま上書き保存（Ctrl+S）。

### 4. 新バージョンとして登録
- ブラウザで Forma（ACC）→ Snowdon Towers → Project Files → 対象ファイルを開く。
- バージョン（Versions）から「新しいバージョンをアップロード」で、保存したファイルを上げる。
- 処理（変換）が終わるまで待つ（数分）。

### 5. Muse へ連絡
- 「V2 上げた」と一言＋手順2のメモ（4つの要素ID/名前）。
- 以後の実測（V2 のインデックス作成、V1→V2 の diff 取得、4操作と diff 結果の突合）は Muse 側で行う。

## 備考
- さらに削るなら #1 追加 と #4 プロパティ変更 の2つでも diff の疎通は取れる（削除・移動の型が未検証になる）。
- この V2 はファイル形式モデルのバージョン登録であり、AEC Data Model 用の「クラウドモデルとして保存＋Publish」とは別物（そちらは不要）。
