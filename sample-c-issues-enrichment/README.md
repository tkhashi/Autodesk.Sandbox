# sample-c-issues-enrichment — 指摘事項 拡張デモ① 要素情報の自動付与

Forma（旧ACC）の指摘事項（Issues）拡張のデモ。要望「指摘事項に、ピン先要素の情報を自動付与したい（階・位置・系統など）」の実現イメージを見せるためのもの。

## デモの内容

- Issue 一覧（デモ用データ6件）。各 Issue はモデル要素にピンされている前提
- 「自動付与を実行」を押すと、Webhook → 要素プロパティ取得 → カスタムフィールド書き戻し、の流れをログで再現し、各 Issue に要素情報が付与される
  - 付与される項目は対象モデルの実データにあるもの：階（レベル）、位置（通り芯マーク／標高）、カテゴリ、タイプ、構造用途、材質、断面、寸法・数量、設計かぶり
- 「生プロパティを見る」で、要素の全プロパティ（Model Derivative API の生応答）を確認できる

## データについて

- 対象: Forma 実環境のサンプルプロジェクト **Snowdon Towers** の構造モデル `Snowdon Towers Sample Structural.rvt`
- 要素プロパティは **実データ**。Data Management API でモデルを特定し、Model Derivative API（metadata / properties）で抽出（2026-11-15）。再抽出は `extract-model-data.mjs`（要 `.env`、sample-a と同じ認証情報）
- このサンプルは構造モデルのため「部屋」「系統」は含まれない。建築・設備モデルであれば同じ仕組みで部屋（Room）・系統（System）プロパティも付与対象にできる
- Issue 側はデモ用モック。検証用ハブでは Issues API が有効でない（404）ため、起票・カスタムフィールド書き戻しは実 API ではなく再現表示。書き戻しは Issues API の PATCH を想定

## 前提・割り切り（デモ仕様）

- ピンは空間ではなく、必ず要素（オブジェクト）に対して打たれる前提とし、要素 ID からプロパティを引く
- 付与項目はモデルのプロパティに存在するものに限る（モデルに無い情報は付与できない）

## 使い方

`index.html` をブラウザで開くだけ（ビルド不要、単一ファイル）。
