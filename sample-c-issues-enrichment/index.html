指摘事項 拡張デモ①：要素情報の自動付与

対象プロジェクト：Snowdon Towers（Forma / 旧ACC 実環境）／ 対象モデル：Snowdon Towers Sample Structural.rvt
要素のプロパティは Model Derivative API で実モデルから抽出した実データ。Issue 側はデモ用データ（前提：ピンは必ず要素に対して打たれる）。
Issue（ピン）要素 ID を保持
→
Webhookissue.created を検知
→
拡張サービスModel Derivative で要素プロパティ取得
→
Issue のカスタムフィールド階・位置・断面・設計かぶり等を書き戻し
付与前は Issue 側に要素情報がなく、モデルを開かないと「どこの・何の」指摘か分からない状態を再現しています。

処理ログ

「自動付与を実行」か、各 Issue の「この Issue に付与」を押してください。
データの出所：要素プロパティは Autodesk Platform Services の Data Management API → Model Derivative API（metadata / properties）で Snowdon Towers の実モデルから抽出（2026-11-15）。
このサンプルは構造モデルなので「部屋」「系統」は含まれず、実データにある項目（階＝レベル、位置＝通り芯マーク／標高、断面、材質、設計かぶり）で構成しています。建築・設備モデルでは同じ仕組みで部屋・系統も対象にできます。
注意：検証用ハブでは Issues API が有効でないため、Issue の起票・更新はデモ用データで再現しています。カスタムフィールドへの書き戻しは Issues API の PATCH を想定したモックです。
