指摘事項 拡張デモ②：実 Issue の取得 → 要素情報の自動付与 → ハイブリッド 3D 表示

Issue は Forma の実 Issue を API で取得し、ピン先の要素 ID からモデル側の情報（要素名・階・通り芯など）を自動で引いて表に付けています。対象は2モデル：DACHsampleproject.rvt（建築・132MB、SVF 66MB）と Snowdon Towers Sample Structural.rvt（構造・軽量、SVF 22MB）。
3D は2段構えです。先行表示は、対象＋周辺だけを切り出した軽量 GLB（Draco 圧縮）を即時表示します。本表示（APS Viewer）は SVF の逐次配信が読み込まれ次第、全体の中での確認に使えます。両パネルのステータス行に表示までの時間を出すので、モデル規模による速度差を比べられます。

先行表示（軽量サブセット・three.js）

対象要素＋周辺（近い順に最大131要素）を事前に切り出して Draco 圧縮した GLB を読みます。対象は橙色、周辺は半透明。ドラッグで回転、ホイールで拡大できます。
Issue を選択すると先行表示します。

本表示（APS Viewer・SVF 逐次配信）

モデルは Autodesk のクラウドから逐次配信で読み込まれます。選択中の Issue の対象要素にカメラを向けた状態で表示し、対象は橙色に色付けされます。Issue のモデルが切り替わると Viewer も読み込み直します。
