指摘事項 拡張デモ②：実 Issue の取得 → 要素情報の自動付与 → 部分3D表示（キャッシュ方式）

対象モデル：DACHsampleproject.rvt（全 2,626 要素）／ Issue は Forma の実 Issue を API で取得し、ピン先の要素 ID からモデル側の情報（要素名・階・通り芯など）を自動で引いて表に付けています。
3D 表示はキャッシュ方式：モデルと変換済み GLB はモデルのバージョンをキーにサーバー側にキャッシュされ、バージョンが変わらなければ再ダウンロード・再変換しません。ブラウザ側にも GLB をキャッシュします。周辺の表示量は下のバー（％）で調整でき、0%＝ピンの要素のみ、100%＝モデル全要素。

① APS Viewer 方式（モデル全体を配信して分離表示）

変換データ（SVF）はクラウドから逐次配信。表示側で対象＋範囲内の要素だけを分離（isolate）し、対象要素は色付け（ハイライト）してカメラを寄せる（フォーカス）。バーを動かすと分離対象が付け替わる。
Issue を選択するとモデルを読み込みます
—

③ 部分表示方式（キャッシュ済み GLB＋表示切替）

サーバーがキャッシュした GLB（モデル全要素）を受け取り、バーの範囲内だけを表示に切り替える。GLB はバージョンが変わらない限り再生成されず、ブラウザにもキャッシュされるため、2回目以降の表示は転送なしで即時。対象は橙色、周辺は半透明ゴースト。
Issue を選択すると GLB を読み込みます
