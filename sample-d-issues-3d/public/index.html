指摘事項 拡張デモ②：実 Issue の取得 → 要素情報の自動付与 → 3D 表示

Issue とモデルはどちらも Forma（ACC）の実データです。Issue は Issues API で、モデルは Forma のドキュメント管理に置かれた RVT を Model Derivative で変換した SVF を Viewer が逐次配信で読みます。対象モデルは Issue のピン先に応じて切り替わります（DACH、Snowdon 構造・建築・ファサードの4モデル）。
Issue を読み込んでいます…

3D 表示（APS Viewer）

Issue をクリックすると対象にフォーカスします（対象以外はすべてゴースト表示）。対象要素は赤く点滅し、ピンが刺さった位置には青いピンを立てます。壁の向こうや地中に埋まった対象でも、ゴースト越しに赤い点滅が見えます。読み込み完了でカメラが全体ビューへ勝手に切り替わることはありません。Viewer 下部のツールバーに、対象要素への再フォーカスのボタンを拡張機能で追加しています。
