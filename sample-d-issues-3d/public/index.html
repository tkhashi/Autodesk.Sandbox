指摘事項 拡張デモ②：実 Issue の取得 → 要素情報の自動付与 → ハイブリッド 3D 表示

Issue とモデルはどちらも Forma（ACC）の実データです。Issue は Issues API で、モデルは Forma のドキュメント管理に置かれた RVT を Model Derivative で変換した SVF を Viewer が逐次配信で読みます。対象は2モデル：DACHsampleproject.rvt（建築・132MB、SVF 66MB）と Snowdon Towers Sample Structural.rvt（構造・軽量、SVF 22MB）。
3D は2段構えです。SVF の読み込みが終わるまでの間は、対象＋周辺だけを切り出した軽量 GLB（先行サブセット）を Viewer の上に重ねて表示し、完了したら自動で隠れて Viewer に引き継がれます。GLB は Viewer 下部のツールバーボタンからいつでも表示・非表示を切り替えられます。
